#Long Range Messenger Project

This is a repository of hardware and software for a SX1262 radio based messageing device I made. This device supports a messaging protocol named Hermes that I created with insperation from protocols like TCP. This messenger runs on an ESP32-S3 using the Arduino framework. All code is built and compiled using Platformio. All hardware is managed through heavy use of FreeRTOS tasks. This allows for easy programming and ensures all hardware is utilized in a timely manner.
